**Abstract**: 
We examine Switzerland’s economic growth using growth accounting and the Solow
and Romer models. Decomposing GDP growth into capital, human-capital-adjusted
labour, and TFP contributions across four sub-periods, we document a shift from TFP
led expansion during the post-war Golden Age to growth increasingly reliant on factor
accumulation. The Solow model captures convergence toward a steady state, while the
Romer framework better explains periods where technological progress drove TFP. The
recent productivity puzzle (high R&D yet flat TFP) reflects the residual nature of TFP
and the concentration of gains in a few multinational sectors, not a true deterioration in
efficiency.

The Python code achieves the following:
* Data Cleaning, imports relevant libraries for use (numpy, pandas, matplotlib, scipy, seaborn), labels variables
* GDP Trend Calculation:  Linear, additive and exponential specifications (using OLS coded from scratch)
* Constructs Time Series of main variables (for sanity checks and formulating hypothesis)
* Extracts Total Factor Productivity measure using variations of Solow and Romer Model
* Checks for robustness with different alpha values
* Growth accounting using different model specifications
* Constructs series for labour productivity i.e., GDP per worker
* Constructs other graphs as required by the analysis
* Visualises the findings
